# 金万山旧居拆分素材

参考图 A 使用 1672 × 941 画布。PNG 为独立素材，使用时按地图布局、实际碰撞占格和角色脚底排序重新摆放。

| 叠放顺序 | 素材 | 布置 |
| --- | --- | --- |
| 地墙 | `tile-floor`、`rear-wall` | 地砖铺满探索区域，墙面覆盖地图后沿 |
| 地面装饰 | `rug-main`、`rug-bed`、`window-light` | 分别放在主桌下、床前和门内地面 |
| 墙边 | `window-curtains`、`coin-wall-banner`、`sideboard`、`book-cabinet`、`bed` | 左侧窗与侧柜，后方书柜与挂饰，右上床 |
| 家具 | `main-desk`、`small-cabinet`、`low-bench`、`tall-potted-plant`、`small-potted-plant` | 保持主桌下方、窄柜左中、矮凳右下的相对位置 |
| 交互道具 | `cold-stove-and-rice-jar`、`debt-ledger`、`ritual-book` | 分别对齐冷灶台 (4,7)、欠账簿 (9,4) 和古书 (14,6) |
| 桌面与陈设 | `loose-pages`、`abacus`、`stacked-documents`、`table-lamp`、`open-coin-chest`、`coin-pile`、`scattered-coins` | 可独立放在家具表面或地面 |
| 前景与出入口 | `right-door`、`folding-screen`、`vines-top-left`、`vines-top-right`、`foreground-coins-left`、`foreground-coins-right` | 门框对齐出口 (18,8)。屏风、边角枝叶和铜钱可叠在角色上方 |

`coin-chest-arrangement` 是钱箱组合件，`book-stand-arrangement` 是含书的小桌组合件。使用组合件时可省去已包含的散件；交互点击区仍由 Demo 管理。

家具的地面接触区域用于占格，高出地面的部分用于遮挡。摆放时保留 20 × 12 地图的通路和各调查点的相邻可达格。
