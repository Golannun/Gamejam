# 小孟婆 · 第三章探索 Sprite

来自参考图 B。待机图保留对应视角的原图轮廓，走动图沿用同一视角的身体、衣服和鞋部纸片。

| 朝向 | 待机 PNG | 四帧图集 PNG |
| --- | --- | --- |
| 向下，正面 | `down-idle.png` | `down-walk.png` |
| 向上，背面 | `up-idle.png` | `up-walk.png` |
| 向左 | `left-idle.png` | `left-walk.png` |
| 向右，侧面镜像 | `right-idle.png` | `right-walk.png` |

- 每帧 256 × 512，透明背景。走动图集 1024 × 512，从左到右播放 0、1、2、3。
- 场景锚点以单帧左上角为原点，取 (128, 488)，对齐角色所在格的地面位置。经过帧允许脚尖略抬。
- 左右循环为近脚落地、远脚经过、远脚落地、近脚经过。朝上、朝下通过脚部交替抬落与身体轻微起伏表现移动。
- 右向逐帧镜像左向，保留时序。侧向符纸随镜像换侧。
- 接入时仅在成功移动时推进走动帧，停步后显示当前朝向的待机图。用实际格间过渡节奏校对播放速度。
